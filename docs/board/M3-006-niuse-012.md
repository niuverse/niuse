## Problem

`niucode-mcp` 0.1.5 is published, but `cargo package -p niuse` still failed:
crates.io `niuse-core` 0.1.11 predates the plan API. The workspace version was
never bumped when `PlanStep` and `compose_with_plan` landed.

## Scope

- Bump the workspace and `niuse-cli` dependency to 0.1.12.
- `cargo package -p niuse-core` passes at 0.1.12.
- `cargo package -p niuse` resolves the registry core 0.1.12, so it needs that
  upload first.
- No upload happens in this card.

## Acceptance

- [x] Workspace and dependency are 0.1.12.
- [x] `cargo check --workspace` passes.
- [x] `cargo package -p niuse-core` passes.
- [x] `niuse-core` 0.1.12 is published.
- [x] `cargo package -p niuse` passes against the registry.
