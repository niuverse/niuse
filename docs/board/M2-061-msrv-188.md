## Problem

The workspace declared `rust-version = "1.85"`, but `cargo +1.85.0 check` failed: several transitive dependencies require 1.88. Worse, `rustyline 19` uses the `cfg_select!` macro, which is still unstable on 1.92, so the interactive REPL had silently raised the effective MSRV beyond the declared one.

## Fix

- Pin `rustyline = "15"`: the API used here (`Editor`, `FileHistory`, `Completer`, `Validator`, history) is unchanged, and it builds on stable 1.88.
- Set `rust-version = "1.88"` and README to match.
- Verified with `cargo +1.88.0 check --workspace --all-targets`.

## Acceptance

- [x] `cargo +1.88.0 check` passes for the whole workspace.
- [x] The stable toolchain still passes the full check script.
- [x] README and Cargo agree.
- [x] Interactive editing behavior is unchanged.

## Notes

A false MSRV is worse than a higher one: contributors on the declared version get a wall of dependency errors. The dependency tree, not our own syntax, sets the floor.
